## ✨ نظرة عامة

نظام إدارة كامل للعيادات والصيدليات مبني من الصفر بدون أي فريم وورك — Vanilla JS خالص. بيانات النظام (مرضى، أطباء، مواعيد، مخزون، فواتير) محفوظة في `localStorage` وبتفضل بعد إغلاق المتصفح، مع نسخ احتياطي واستيراد بصيغة JSON.

## 🖥️ الموديولات

| الموديول | الوظيفة |
|---|---|
| 🔷 لوحة التحكم | مؤشرات حية (مواعيد اليوم، المرضى، إيراد الشهر، تنبيهات المخزون) + رسم بياني للإيرادات |
| ☺ المرضى | CRUD كامل + بحث فوري بالاسم أو الهاتف + ملاحظات طبية |
| ✚ الأطباء | كروت أطباء + تخصصات + سعر الكشف + حضور صباحي/مسائي |
| ◷ المواعيد | حجز مواعيد + فلترة بالتاريخ والحالة + إنجاز/إلغاء بضغطة |
| ❋ الصيدلية | مخزون أدوية + حدود إعادة الطلب + تنبيه نفاد وانتهاء صلاحية + إضافة كمية |
| ▤ الفواتير | إنشاء فاتورة بأصناف متعددة مع خصم تلقائي من المخزون + طباعة فاتورة احترافية |
| ▤▤ التقارير | رسوم بيانية مرسومة بـ Canvas من غير مكتبات: إيراد ٦ أشهر، الأدوية الأكثر صرفاً، مواعيد كل طبيب، صحة المخزون |
| ⚙ الإعدادات | بيانات العيادة + تصدير/استيراد نسخة احتياطية JSON + إعادة ضبط |

## 🎯 تحديات تقنية اتحلت في المشروع

- **مخطط Reactivity بدون فريم وورك**: كل شاشة بتعيد رسم نفسها من طبقة البيانات المركزية `Store`
- **رسم بياني بـ Canvas API من الصفر** — بدون Chart.js ولا أي مكتبة خارجية
- **نظام RTL كامل** مع خط IBM Plex Sans Arabic وتخطيط مرن من الموبايل للديسكتوب
- **طبقة CRUD عامة** واحدة بتخدم كل المجموعات (مرضى/أطباء/أدوية/مواعيد)
- **طباعة الفواتير** في نافذة مستقلة بستايل خاص

## 🚀 تشغيل محلي

```bash
git clone https://github.com/noooreldein/noor-clinic.git
cd noor-clinic
# افتح index.html مباشرة في المتصفح — لا يحتاج سيرفر ولا تثبيت
```

**بيانات الدخول الافتراضية:** `admin` / `admin123`
